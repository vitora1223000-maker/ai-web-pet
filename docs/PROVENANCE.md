# 来源与公开边界

本版本代码、模板和测试在本项目独立编写，未复制来源不明的历史pet pipeline。通用流程来自制作经验；无内部角色原图、专属设定或聊天记录。

Pillow 12.3.0是外部安装依赖，不随仓库捆绑。已核对上游[MIT-CMU许可证](https://github.com/python-pillow/Pillow/blob/12.3.0/LICENSE)和[PyPI版本](https://pypi.org/project/Pillow/12.3.0/)。Python、浏览器和测试用Node由用户环境提供，仓库不分发二进制，也没有npm依赖。

项目所有者已确认源码与配套文档采用[MIT License](../LICENSE)。本仓库未包含的角色形象、角色设定和品牌素材不在授权范围内。用户角色资产不纳入代码许可，外部AI输出使用条件由服务与素材来源决定。
