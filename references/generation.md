# Generation handoff

Use assets/templates/GENERATION_HANDOFF.md for design, reference or action requests. Routes are native, external or user_supplied; they share the contract. Provider-specific options may be appended but never override the character lock, contact map or required output.

Specify original input references, purpose, lock version, ordered views/poses, camera/scale, margins, background and output layout. Return original full-resolution files, not screenshots. Prefer true alpha; if a model returns chroma, explain that an external transparency step is needed before import. Never claim the helper removes backgrounds.

On return, associate files with the request and reference version; inspect identity, anatomy, contact, crop and layout before splitting/import. Extra limbs, swapped asymmetric features, wrong contact and clipped silhouettes are failures. Mechanical format validation cannot accept these.

Retain source originals separately from processed frames. If external generation is pending, save the brief and missing outputs and resume when supplied; do not substitute a provider or silently spend credits. Native image generation must use available image tools with direct identity reference. No generation capability is bundled here.
